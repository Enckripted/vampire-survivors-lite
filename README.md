# vampire-survivors-lite

A Vampire Survivors "clone" I made in Godot to try and become familiar with the basics of the engine. This was a very programming focused project and because of it I ran out of time to draw assets, so there is just default sprites and colored shapes. Current features implemented are:

- A main menu
- 2 enemy types (melee/ranged, 3 melee variations)
- Auto sword slash
- Collectables/score

# Running the game

Just download the game from the releases if you're on Windows, and run the executable.

# How to play

White circle marks your auto attack range, which is a sword slash that targets the nearest enemy. It strikes in a small area so you can hit multiple enemies at once. There are three different variants of melee enemies that run towards you to hit you, and a wizard (pink enemy) who charges up orbs to hit you. When your HP hits 0, you lose.
